# Security policy

PC Monitor is a small open-source beta project. The current source version is v0.9.7 (candidate). See [Releases](https://github.com/smety-dev/PC-Monitor/releases) for the currently published binaries. No formal support window or response-time guarantee is established.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature under the repository's **Security** tab if it is enabled. If private reporting is unavailable, open a public issue requesting a private contact method without including vulnerability details, secrets, or exploitable instructions.

Include the affected version, impact, reproduction details and relevant environment privately. Do not test on systems you do not own or have permission to test.

The portable executable is unsigned. Obtain it from the official [releases](https://github.com/smety-dev/PC-Monitor/releases) and verify the accompanying SHA-256 checksum. A checksum verifies integrity against the published value, not publisher identity. The project does not automatically request administrator elevation or upload telemetry.
